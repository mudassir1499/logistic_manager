{% extends 'portal/base.html' %} {% load static %} {% comment %}============================================================================= SIGNED-IN PORTAL SHELL ============================================================================= Every page behind the customer login extends this instead of portal/base.html. Why it exists: base.html serves the public marketing site, and the signed-in portal was wearing that chrome. Ten destinations — Dashboard, Portfolio, Orders, Cart, Requests, Products, Ledger, Support, Notifications, account — were competing for room in one horizontal navbar, which on a phone collapsed into a single undifferentiated hamburger list. A marketing navbar tops out at about five items; an operational tool needs somewhere for the eleventh. The shell keeps base.html's , scripts, analytics and toast container by inheriting them, and replaces only the navigation, main region and footer. So the public site is untouched by anything in this file. Child pages override {% block page %}, NOT {% block content %} — content is used here to build the shell. ============================================================================={% endcomment %} {% block body_class %}portal-app{% endblock %} {% comment %}base.html offsets the body for its fixed navbar.
