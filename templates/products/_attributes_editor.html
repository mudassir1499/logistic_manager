{% comment %} Free-form product specification editor, shared by the Add and Edit product forms. Context: editor_id unique DOM id for this instance, e.g. "addProductAttrs". Both forms live in the same document, so every id here must be namespaced or the two editors write into each other. Rows post as two parallel arrays, attr_name[] and attr_value[], matched by position — see products.views._save_attributes. Row order is display order. A form that submits NO attr_name[] input at all leaves existing attributes untouched (that is what _save_attributes checks for), which is why the hidden sentinel below is always present: it guarantees the key exists even when the operator deleted every row, so "delete them all" is a saveable state rather than a silent no-op. {% endcomment %}
