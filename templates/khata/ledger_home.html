Import Ledger Entries

Columns — date, customer, entry_type, amount, currency, description. Any order; customer, entry_type and amount are required.

  • customer must match a customer name already in the system, exactly (case does not matter).
  • entry_type accepts credit / debit, and also payment, received, charge, invoice, cr, dr.
  • date reads YYYY-MM-DD or DD/MM/YYYY. Blank means today.
  • amount may carry separators and symbols — 1,250.00 and AED 1250 both work.

An exported CSV can be edited and uploaded back as-is.

Safe to repeat. Rows already in the ledger are skipped, so re-uploading the same file will not double any balance. If a single row is wrong the whole file is rejected and nothing is written.
